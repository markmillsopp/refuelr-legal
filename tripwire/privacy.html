TripWire

Privacy policy

Effective 25 August 2026. Updated 7 September 2026.

TripWire is a private family gate alert app. It does not contain advertising. It does not sell personal information. It does not use data for cross-app tracking.

Data TripWire handles

  • Account email and Firebase user identifier.
  • Gate sensor names, identifiers, status, and configuration.
  • Gate alert events and their times.
  • Notification settings and push notification tokens.
  • Basic platform information needed for push delivery.

During pairing, the app sends home Wi-Fi details directly to the nearby gate sensor. The app does not save the Wi-Fi password in the TripWire cloud database.

How data is used

Data is used only to authenticate approved family members, configure gate sensors, display alert history, and deliver gate notifications.

Service provider

TripWire uses Google Firebase for authentication, database storage, server processing, and push notification delivery. Data may be processed where Google operates these services.

These public support and privacy pages are hosted using GitHub Pages.

Retention and deletion

Alert history remains until its gate sensor is removed. Removing a sensor deletes its stored alert history. Security replay records expire after seven days. Account and notification records remain while the private family service is active.

For privacy questions or to request deletion of an account or remaining data, email refuelr@outlook.com. The TripWire owner will remove the account and associated cloud data.

Security

Access requires an approved account. Gate alerts use signed requests. No internet service is perfectly secure, but TripWire limits access and stores only data needed for the alert service.

Children

TripWire is not offered as a public child-directed service. Family access is controlled by the TripWire owner.

Changes

This page will be updated when TripWire data handling changes.
